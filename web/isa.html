One program, three instruction sets

Switch between RISC-V, MIPS and x86-64. The same seven programs are written in each, assembled to real machine code, and run cycle by cycle on a model of a typical pipeline for that architecture. All three get the same memory, the same multiply/divide timing and the same branch predictor, so what differs is the instruction set itself.

    Pipeline chart

    Rows are instructions in fetch order, columns are cycles. On MIPS, watch the instruction after every branch: it runs either way (the delay slot). On x86-64, an instruction of several micro-ops holds DECODE for several cycles.
